# Squire

Landing page and privacy policy for **Rideshare G2 by Squire**, a plugin for Even G2 glasses.

Static site: open `index.html`, or run `npx serve .`. Deploy the folder as-is to any static host (Vercel, Netlify, GitHub Pages, S3). `assets-src/` and `tools/` are not needed in production.

See `CLAUDE.md` for structure, design system, how the G2 display overlays work, and open items before launch.
